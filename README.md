## 📖 專案簡介（Overview）

台灣高齡化使骨健康資訊整合與長期追蹤日益重要；內政部統計指出，2025 年 10 月底台灣 65 歲以上人口占比為 19.9%。骨鬆照護涵蓋骨密度評估、治療追蹤與衛教，骨科（Orthopedics）、神經外科（Neurosurgery）醫師及個案管理人員在日常門急診實務中，需同時整合 DXA 報告、病史、健保第 5.6 節給付規定、用藥日期與衛教資訊。然而現有資訊分散於報告、病歷與規範文件，單一模型分數或自由生成的回答，難以完整處理來源版本、缺件及人工確認。

本專題提出 **OsteoGuard AI Agent**，定位為供骨科、神經外科醫師及個案管理人員使用之**證據導向資訊整合與輔助決策原型（CDSS）**（病患僅透過醫療人員檢閱後的圖卡取得資訊）。系統採**任務分離與受限工具白名單架構**：
- **研究分析與規則執行分離**：以 `NHANES 2017–March 2020` 串聯資料建立可重現之 `OSQ060`「自述曾被醫師告知骨鬆」分類參考（`p_history` + SHAP）；有效部位 DXA 判讀、版本化健保第 5.6 節條件核對、已確認醫囑之曆月追蹤時間軸與術式相關複查清單則由獨立且確定性的程式工具分別處理，不混成單一風險分數，亦不由告知史模型輸出個人骨折或內固定失敗機率。
- **人機協作與來源治理**：由受限 Agent 依查詢拆解任務、追問缺件、透過版本化檢索取得核准來源，經驗證器檢核數值、引用與任務邊界後，產出分離的 `O1–O4` 四面板與附來源草稿，強制經**人工修改與確認（Human-in-the-Loop）**後始可匯出。

## 🎯 核心研究脈絡（A–F）— 痛點假設、功能與證據邊界

### 1. 研究動機與背景（Attention Getter & Background）
- **高齡社會背景**：2025 年 10 月底台灣 65 歲以上人口占比達 19.9%；骨鬆長期照護需要跨科整合骨密度、病史、給付條文與用藥時程。
- **公開研究資料與指引依據**：NHANES 官方提供 50 歲以上受試者的股骨 DXA 及骨鬆問卷資料，支持公開資料分析研究；ISCD 2023 區分骨密度診斷分類與骨折風險評估，支持將模型分類與臨床 DXA 判讀分開解釋。
- **證據邊界聲明**：上述來源不直接證明台灣外科場域之漏診率或轉介現況；下述臨床工作流需求在本期視為**設計假設**，實際需求強度、工時節省、核扣改善與照護效益仍須另做場域研究。

### 2. 五項需求痛點、本期功能與不能據此宣稱的成效（Problem & Boundaries）
| 需求／痛點假設 | 本期功能 | 本期不能據此宣稱的成效 |
| :--- | :--- | :--- |
| 1. 急門診資料分散，需人工複查 | 顯示缺件、使用者註記與人工複查待辦 | 自動辨識微小壓迫骨折（如 Genant Grade 1）、轉移瘤或降低漏診 |
| 2. 健保第 5.6 節給付條件與文件核對繁複 | 版本化規則核對、條號、缺件與待確認事項清單 | 保證給付核准或避免健保核扣 |
| 3. 衛教與病歷整理反覆（含牙科 MRONJ 溝通） | 附來源的白話衛教圖卡草稿、牙科照會確認問題與 SOAP 草稿 | 提升遵從性、信任度或節省既定工時 |
| 4. 跨科追蹤與回診日期難整合 | 既有確認醫囑之曆月時間軸與追蹤待辦 | 已降低流失率或改善跨科轉介率 |
| 5. 圍術期骨質資訊需整理（脊椎與關節手術） | 依術式顯示骨質評估複查清單與適用指引來源 | 輸出個人螺釘鬆脫機率、選擇術式或決定延後手術 |

### 3. 解決方案與分工定位（Cure — Agent vs. 固定規則）
- **固定規則程式**適合閾值、條件與日期計算，但自然語言需求需額外解析與互動設計；規則仍是本系統的重要元件。
- **表格模型（LR / RF / XGBoost）**可分析既定 X 與 `OSQ060` 告知史的統計關聯，無法憑橫斷面告知史回答影像病灶、未來骨折或手術結果。
- **OsteoGuard AI Agent（雙層分工）**：讓受限 Planner 依自然語言查詢拆解任務、選擇白名單工具（最多 8 個 task）、追問缺件並組織證據；數值推論（單一鎖定模型）、ISCD DXA 閾值、版本化健保條件、曆月排程與術式複查清單則交由獨立程式工具執行，並將與固定工作流、無檢索 LLM 草稿在相同 24 個合成案例下比較完成率與穩定性。

### 4. 研究方法（Development）
- **資料來源**：串聯 `NHANES 2017–March 2020` 四份 XPT（`P_DXXFEM`、`P_DEMO`、`P_BMX`、`P_OSQ`），並整合衛生福利部中央健康保險署公開《藥品給付規定》第 5.6 節（PDF 第 15–17 頁）及國際指引（ISCD 2023、AAOMS 2022、CNS 2021、Endocrine Society 2019、BHOF 2022）。
- **模型與可解釋性**：離線以相同切分比較 `Logistic Regression`、`Random Forest` 與 `XGBoost` 預測 `OSQ060`，依驗證集 PR-AUC（Average Precision, AP）選定單一模型鎖定供線上參考，搭配 `SHAP` 解釋模型分數，不將歸因當作因果或健康程度。
- **RAG 與來源治理**：核准來源依 `clinical / reimbursement / data_definition` 分類、記錄 `sha256` 與有效日期，先依種類／藥品／有效日過濾再以 BM25＋向量檢索，且不將檢索文件內任何潛在提示視為工具指令。

## 🧪 實驗設計與預期成果（Experiments & Expected Outcomes）

| 項目 | 規劃內容 |
| :--- | :--- |
| **Dataset** | NHANES 2017–March 2020（`P_DXXFEM` 4,593 → 有效掃描 3,545 → 50 歲以上且 `OSQ060` 有效標籤 **3,530 筆**［380 陽性／3,150 陰性］；體測完整敏感度子集 3,511 筆）+ 健保署公開藥品給付規定 |
| **Baseline Models** | Logistic Regression、Random Forest、XGBoost（相同分層 80/20 保留測試、訓練內 Stratified 5-fold、20 組 RandomizedSearch、`seed=42`） |
| **Evaluation Metrics** | 主要指標 **PR-AUC（Average Precision, AP）**，另報陽性 Precision／Recall／F1、Macro-F1、Accuracy、ROC-AUC、Brier score 與校準圖（1,000 次分層 Bootstrap 95% CI） |
| **Agent 功能驗收** | **24 個預寫合成案例（A01–D06）**＋固定工作流／無檢索 LLM／受限 Agent 三條件 × 3 次重複（72 次執行）比較；路由與端到端目標 $\ge 22/24$、數值／日期與關鍵引用 100% 一致 |
| **應用展示與限制** | 僅作合成案例與內部展示；期末不安排專業人員回饋，不宣稱臨床驗證、信任或工時節省 |

### 三階段驗證與預期產出
- **第一階段：資料盤點與 ML 模型比較**：已完成本地 3,530 筆有效樣本盤點（`PROPOSAL.md` 第 6.1 節）。後續比較人口學基準、+BMD、+BMC/Area、+部位比值四組特徵增益與 OOF F1 閾值／Sigmoid 校準表現，選定單一模型鎖定供線上參考，搭配 SHAP 說明歸因與誤分類案例。
- **第二階段：Agent 內部功能測試（A01–D06）**：覆蓋 A 類（模型／DXA 任務分離與品質碼）、B 類（健保版本與衝突狀態）、C 類（曆月月底截斷如 `2026-08-31` + 6 月 $\rightarrow$ `2027-02-28`）、D 類（術式排除、`THA/TKA` 不出椎弓根螺釘提醒、Prompt Injection 防護與未確認匯出阻擋）。
- **第三階段：模擬臨床情境展示**：由組員以合成案例操作四面板 `O1–O4`、檢視 `trace`、失敗狀態與人工修改確認流程。

### 3. 📤 系統四大結構化輸出面板（O1–O4 Output Specification）
以清楚的來源、數值、SHAP 解釋、缺件與限制提示支持人工判斷；未經人工檢閱與確認不得匯出確認版報告，且不宣稱已串接正式 HIS 或申報系統：

1. **O1 研究與 DXA 結果**：分列 `p_history` + SHAP 歸因、有效部位 DXA 判讀（ISCD 2023 適用族群限制），以及依人工確認術式產出之複查待辦（僅 `spinal_fusion` 且具適用來源時顯示脊椎與螺釘相關複查項，`THA/TKA` 排除椎弓根螺釘提醒；不產生單一綜合風險分數或螺釘失敗機率）。
2. **O2 給付條件卡**：逐條列條號、來源、生效版本、符合／不符／待確認狀態與缺件清單；來源未核實時標示 `source_unverified`，不用 LLM 自行補成符合。
3. **O3 時間軸**：顯示已確認醫囑之曆月追蹤日期、行政回診與待檢視療程節點；若需更改治療，轉為醫師待辦，不自行決定藥物或停藥／換藥日。
4. **O4 SOAP／衛教草稿**：基於可支持的工具結果與核准文件轉譯，列牙科 MRONJ 照會確認問題（依 AAOMS 2022，不提供固定停藥或拔牙安全窗口）及衛教確認事項；未有適用營養／運動指引時僅列待討論事項，不自動產生固定補充劑量或運動處方。
